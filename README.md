# ✂️ Urban Cuts — Modern Barber Shop

A modern, responsive barber shop website built using **HTML, CSS and JavaScript**.

Urban Cuts is designed as a client-style business website with a bold visual identity, service showcase, gallery, reviews, location information and appointment booking flow.

## ✨ Features

* 💈 Modern barber shop landing page
* 📱 Fully responsive design
* 🎬 Video-based hero section
* ✨ Smooth scroll animations
* ⏳ Loading animation
* 📋 Services and pricing section
* 🖼️ Gallery section
* ⭐ Customer reviews carousel
* 📍 Location and opening hours
* 📅 Appointment booking form
* 📲 WhatsApp booking integration
* 🍔 Responsive mobile navigation
* 🎨 Custom modern UI design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Responsive Web Design

## 📅 Booking System

The booking form is implemented as a **front-end demonstration**.

When a user submits the form, the booking information is prepared and sent through WhatsApp.

For a production website, the booking system could be connected to a proper backend, database or booking service.
